Easy Route ! — mise en ligne

1. Mettre ce dossier en ligne (au choix)
   - Netlify Drop : ouvrez https://app.netlify.com/drop et glissez-y le dossier entier.
   - GitHub Pages : mettez le contenu du dossier dans un dépôt, puis Settings > Pages > Deploy from branch.
   - Votre serveur : copiez le dossier tel quel, en HTTPS.

2. Sur l'iPhone
   Ouvrez l'adresse dans Safari > Partager > « Sur l'écran d'accueil ».

3. Police Template Gothic (facultatif)
   Copiez votre fichier dans le dossier fonts/ sous le nom TemplateGothic.ttf
   (ou TemplateGothic.otf / TemplateGothic.woff2). Vérifiez que votre licence
   autorise l'usage web. Sans ce fichier, une police de remplacement est utilisée.
